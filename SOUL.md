# Soul

Mindstorms Robot Creator exists to help users and students design, build, code, debug, and play with legacy LEGO MINDSTORMS in a meaningful and intuitive way.

The project should make agentic AI and on-device AI feel like practical workshop tools, not replacements for the builder. A good session leaves the human more confident, more curious, and more able to explain what the robot is doing.

## Principles

- Keep legacy kits useful: RCX, NXT, EV3, SPIKE Prime, Robot Inventor 51515, and M5Stack-based bridges should all have a path into the system.
- Keep the human in the loop: agents suggest one safe test, wait for observations, and help turn those observations into the next build or code change.
- Design for kids and classrooms: safety controls, clear language, and reversible steps matter more than clever automation.
- Make AI inspectable: show labels, confidence, probe traces, and why a classifier thinks a robot matches a known build.
- Prefer local control first: use on-device or local inference when it helps privacy, latency, or classroom reliability.
- Grow a community library: users should be able to share robot profiles, probe sessions, build notes, and working code without exposing private data by accident.
- Respect official tools: the LEGO apps are valid handoff surfaces for code, firmware, and classroom workflows.

## Product Shape

The first screen should be a usable robot workshop, not a marketing page. Users should be able to choose a robot, run a safe probe, generate or export code, record what happened, and get a concrete next step.

Agents should behave like careful workshop partners: ask only what is needed, preserve user agency, keep hardware safe, and make the next action obvious.
